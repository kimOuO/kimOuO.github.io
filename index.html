利用閒置時間改善 SSD GC 之 Long Tail Latency
2024 · 國立臺灣科技大學 電子工程系 112學年度實務專題 · 指導教授：吳晉賢

針對 SSD Garbage Collection 觸發長尾延遲問題，以強化學習（Deep Q-Learning）預測系統閒置時間， 讓 GC 在 Idle Time 執行，降低強制 GC 的觸發頻率。核心挑戰在於以 Cython 橋接 Python RL Agent 與 C++ SSD 模擬器 MQSim，實現跨語言環境整合。

  • 設計 Deep Q-Learning 模型（DQN），state 空間 2×2×4（16 種組合），reward 以 70th / 90th / 99th percentile respond time 為基準，action 二元（執行 GC / 不執行）
  • 使用 Cython 橋接 Python RL Agent 與 C++ MQSim 模擬器（嘗試 ctypes 後改用 Cython），解決跨語言變數交換問題；訓練以每輪 100,000 筆 SNIA IOTTA 企業伺服器 I/O trace 驗證，完成後執行 long memory training 並儲存模型
  • 實驗結果（MQSim NVMe MLC Flash 配置）：在最高響應延遲時間段（~4.95×10⁷ time unit 區間）RL 策略的高延遲事件次數明顯少於原始 trace，4.8–4.9×10⁷ 區間兩者曲線接近重疊
  • 中段響應時間與 baseline 幾乎相同，驗證 RL 排程策略在不拖累正常 I/O 效能的前提下，選擇性抑制尾端極端延遲事件
Reinforcement Learning Deep Q-Learning Python C++ Cython MQSim SSD / Storage
