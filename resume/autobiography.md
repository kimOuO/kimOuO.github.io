同一時期，我也參與了 MySphere 英文分級故事學習平台的開發，這是學海計畫與 SparkAmplify 及東華書局的合作專案。我負責資料庫管理與 API 開發，內建學習進度追蹤 API 與 LLM 智能問答 Chat，並搭建 Docker 容器化部署與 Nginx 反向代理的完整服務架構，同時建立 Harbor Image 管理流程與 GitHub Actions CI/CD，規範團隊 Git Workflow 協作。

## 專案與技術深度

在碩士入學前，我參與了國科會 6G AI/ML 訓練／推論平台的開發與維運，該平台覆蓋 O-RAN 基礎架構、KubeFlow 訓練環境與 Dify 智慧化操作介面，以 AR/VR QoS 為核心應用。我負責雙節點混合部署（Agent Node + Inference Node），維運 20 個以上的容器服務，橫跨 Docker Space 與 Kubernetes Space。此外，我串接意圖驅動平台，以 AI Agent 形式控制整個平台。該平台於 EuCNC 2024（比利時）進行 AR/VR QoS 即時推論現場展示，並於 COSCUP 2024 發表成果。

在碩士期間，我擔任微積分課程助教，為了方便課務銜接與管理，我獨立以 React + Django + DB 全端開發了成績登記與考卷管理系統，並開發自動出題 AI Agent，透過 Tool Use 內嵌 Word 工具，自主生成完整考卷文件。這個經驗展現了我在發現實際需求時，會主動運用技術能力解決問題的特質。

我的大學部實務專題為「利用閒置時間改善 SSD GC 之 Long Tail Latency」，指導教授為吳晉賢老師。我使用 Deep Q-Learning 預測 SSD 系統閒置時間，主動在 Idle Time 排程 GC，降低 Forced GC 觸發頻率以改善長尾延遲，並以 Cython 橋接 Python RL Agent 與 C++ SSD 模擬器 MQSim，以 100,000 筆 SNIA IOTTA 企業伺服器 I/O trace 完整驗證，有效降低長尾延遲發生機率。
